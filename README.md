# 📡 3-Stage Broadband 90° Hybrid Coupler (3단 광대역 90도 하이브리드 커플러 설계)

본 저장소는 **마이크로파회로설계** 과목의 최종 프로젝트로 진행된 **'3단 광대역 90도 하이브리드 커플러'**의 설계, 최적화 및 시뮬레이션 결과를 상세히 담고 있습니다. 
RF 통신 시스템에서 필수적인 하이브리드 커플러의 '광대역(Broadband)' 특성을 확보하기 위해 기존 1단 커플러의 한계를 극복하는 3단(Multi-stage) 구조를 도입하였습니다. 특히 수학적 해를 도출하기 힘든 복잡한 비선형 방정식을 MATLAB을 통해 수치해석적으로 풀어내고, 실제 PCB 공정의 물리적 한계를 고려한 임피던스 매칭 기법을 적용하여 완성도 높은 설계를 검증했습니다.

## 🎯 1. 엄격한 설계 목표 (Design Specifications)

단순한 동작 확인을 넘어, 실제 산업 현장에서 요구되는 매우 엄격한 수준의 오차 범위를 목표로 설정했습니다. 이상적인 커플러 성능(반사/격리 0, 완벽한 3dB 분배, 정확한 90도 위상차)에 최대한 근접하면서 대역폭을 한계까지 끌어올리는 것이 핵심입니다.

* **반사계수(S11) & 격리도(S41):** < -20dB (전력 누수 및 간섭 최소화)
* **전력 분배 오차 (S21, S31):** 이상적 분배율(-1.25dB, -6.02dB) 대비 **10% 오차 이내** 허용
  * `-1.71dB < S21 < -0.84dB`
  * `-6.48dB < S31 < -5.61dB`
* **위상차 (Phase Error):** 중심 주파수($f_c$)에서 **0.1° 이내** (90° ± 0.1° 달성)

## 🧠 2. 핵심 설계 이론 및 MATLAB을 활용한 최적해 도출

### 2.1 ABCD 행렬을 통한 수식화의 한계
3단 하이브리드 커플러 설계 시, 각 전송 선로를 대칭 구조(a, b, c)로 정의하고 **ABCD 행렬(Matrix)**을 이용하여 회로를 해석합니다. 이를 통해 다음과 같은 두 가지 핵심 수식을 얻을 수 있습니다.

* **정합 조건 (Matching):** $c^2(1+a^2) = b^2(1+a^2+2ac-b^2)$
* **분배 조건 (1:3 Power Division):** $(b^2(a+c)-ac^2)^2 + (c^2-b^2)^2 = 2b^3(b^2(a+c)-ac^2)$

**[문제 발생]** 위 조건들을 만족하는 특성 임피던스(Series Z, Shunt Z)를 구해야 하지만, 수식을 보면 미지수의 개수와 방정식의 차수가 높아 단순한 대수적 계산(손계산)으로는 **닫힌 형태의 해(Closed-form solution)를 구하는 것이 수학적으로 불가능한 비선형 방정식(Non-linear Equation)** 시스템이 됩니다. 

### 2.2 MATLAB 수치 해석을 통한 Design Chart 최적화
방정식을 직접 풀 수 없는 문제를 해결하기 위해 **MATLAB을 활용한 수치 해석적 접근(Numerical Analysis)**을 시도했습니다. 

1. **변수 스윕(Sweep) 및 교차점 탐색:** 특정 임피던스 값들을 미세한 단위로 변경(Sweep)해가며 Series Impedance와 Shunt Impedance 간의 상관관계를 계산했습니다.
2. **Design Chart 시각화:** 계산된 결과를 바탕으로 `Shunt Z vs Series Z` 그래프를 그렸습니다. 
3. **최적의 설계점 도출:** 그래프 상에서 Outer Arm($Z_a$)과 Inner Arm($Z_c$)의 임피던스 궤적이 완벽하게 교차(Intersection)하는 점을 찾아냈습니다. 이 교차점이 바로 정합 조건과 분배 조건을 동시에 만족하는 최적해입니다.
4. **결과 값:** MATLAB 최적화를 통해 다음과 같은 정확한 임피던스 값을 추출할 수 있었습니다.
   * $Z_b = 23.5 \Omega$
   * $Z_a = 98.65 \Omega$
   * $Z_c = 83.77 \Omega$

## 🛠️ 3. RF 회로 설계 시 물리적 한계와 공정 제약 극복

MATLAB으로 완벽한 임피던스 값을 얻었음에도 불구하고, 이를 실제 물리적인 마이크로스트립(Microstrip) 선로로 구현할 때 또 다른 심각한 문제가 발생했습니다.

### 🚨 문제점: 고 임피던스 구간의 치명적인 선로폭(Trace Width) 한계
RF 회로에서는 임피던스가 높을수록 물리적인 선로의 폭이 얇아져야 합니다. 
도출된 설계 과정 중 특정 구간에서 **186.6Ω**이라는 매우 높은 특성 임피던스가 요구되었는데, 이를 계산해보니 **선로 폭이 무려 0.062mm** 수준으로 얇아져야 했습니다.
* **상용 공정의 한계:** JLC PCB, 한샘 디지텍 등 상용 PCB 제작 업체의 최소 보증 선폭은 **0.1mm**입니다. 0.062mm는 물리적으로 제조가 불가능합니다.
* **에칭 오차(Etching Tolerance):** 간신히 제조한다 하더라도, 동판을 녹여내는 에칭 과정에서 발생하는 미세한 오차만으로도 선로가 끊어지거나 임피던스가 심각하게 틀어지게 됩니다.

### 💡 해결 방안: 임피던스 변환 및 특수 기판 적용
이러한 물리적/공정상 한계를 극복하기 위해 다각도의 엔지니어링 기법을 도입했습니다.

1. **저유전율 & 두꺼운 기판 사용:** 
   * 비유전율($\epsilon_r$)이 낮고 두꺼운 특수 고주파 기판을 사용하여 동일 임피던스 대비 요구되는 선폭을 물리적으로 넓혔습니다.
   * **적용 기판:** 고성능 RF 전용 기판인 Rogers `RT/duroid 5880` ($E_r=2.2$, 두께 $H=1.575mm$)
2. **$\lambda/4$ 파장 임피던스 변환기(Quarter-wave Transformer) 적용:** 
   * 높은 임피던스(186.6Ω) 선로를 억지로 얇게 구현하는 대신, 보다 넓은 폭을 가질 수 있는 낮은 특성 임피던스로 1차 설계를 변경했습니다.
   * 이후 해당 임피던스를 보정하기 위해 **$\lambda/4$ 임피던스 변환기($Z_T = \sqrt{Z_{in} \cdot Z_{load}}$)** 구조를 중간에 배치하여 완벽한 정합(Matching)을 수행했습니다.
   * *(예: $Z_T = \sqrt{25 \times 50} \approx 35.355\Omega$ 적용을 통해 극단적으로 얇은 선로 회피)*

## 📊 4. 단계별 시뮬레이션 결과 및 대역폭(Bandwidth) 분석

설계 검증은 크게 3단계(TLIN $\rightarrow$ MLIN $\rightarrow$ EM)의 점진적 시뮬레이션으로 진행되었으며, 각 단계마다 1단/2단/3단 구조의 대역폭 증가폭을 정밀하게 비교했습니다.

### 1) TLIN (Ideal Transmission Line) 시뮬레이션
물리적 기생 성분을 배제한 이상적인 전송선로 환경에서의 검증 결과입니다. 단수가 증가함에 따라 대역폭이 비약적으로 넓어지는 것을 확인했습니다.
* **1단 커플러 대역폭:** 256 MHz
* **2단 커플러 대역폭:** 464 MHz
* **3단 커플러 대역폭:** **500 MHz (최대)**

### 2) MLIN (Microstrip Line) 시뮬레이션
실제 PCB 기판(MSUB)의 두께와 유전율, 그리고 $\lambda/4$ 파장 변환기를 적용한 현실적인 시뮬레이션입니다. (a, c 선로 간 0.3mm의 미세한 길이 차이가 선로 두께보다 얇아 90도 꺾임(Mitered bend)이 불가한 기하학적 제약까지 모두 반영됨)
* **2단 커플러 대역폭:** 200 MHz
* **3단 커플러 대역폭:** **424 MHz** 
  * 중심 주파수 위상 오차: 89.95° (목표치 0.1° 이내 완벽 만족)

### 3) EM (Electromagnetic) 시뮬레이션
레이아웃 구조 간의 공간적 커플링(Coupling) 및 전자기적 기생 성분(Parasitic)까지 모두 포함시킨 최종 검증 단계입니다.
* **2단 커플러 대역폭:** 197 MHz
* **3단 커플러 대역폭:** **437 MHz** 
  * 중심 주파수 위상 오차: 90.08° (목표치 0.1° 이내 완벽 만족)

## 🏆 5. 최종 결론 (Conclusion)

본 프로젝트를 통해 하이브리드 커플러의 **단수(Stage)가 늘어남에 따라 대역폭(Bandwidth)이 확연하게 넓어지는 광대역 특성**을 수치적, 물리적으로 모두 증명했습니다.

1. **MATLAB 최적화 성공:** 닫힌 해(Closed-form solution)가 존재하지 않는 복잡한 비선형 설계 방정식을 MATLAB의 Sweep 및 Design Chart 기법을 통해 완벽한 최적 임피던스 값으로 풀어냈습니다.
2. **제조 공정 한계 극복:** 상용 PCB 공정의 0.1mm 선폭 제약을 $\lambda/4$ 트랜스포머 매칭 기법과 RT/duroid 5880 고주파 기판 선정을 통해 훌륭하게 우회 및 해결했습니다.
3. **최종 스펙 달성:** 결과적으로 최종 3단 EM 시뮬레이션 기준 **437MHz의 넓은 광대역**을 확보하면서도, **전력 분배 오차 10% 이내**, **위상 오차 0.1° 이내**, **S11/S41 <-20dB**라는 매우 까다로운 초기 설계 목표치를 100% 달성하는 쾌거를 이루었습니다.
